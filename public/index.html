CONEXIÓN CON CLAUDE CODE

Para ver a tus agentes, la oficina añade unos hooks a tu configuración de Claude Code (). Cada hook es un comando curl que avisa a la oficina cuando un agente usa una herramienta. Si la oficina está cerrada no pasa nada. Solo se tocan las entradas de la oficina, y la primera vez se guarda una copia de seguridad del archivo (settings.json.bak-oficina).

Los cambios se aplican a las sesiones de Claude Code que abras a partir de ahora.
